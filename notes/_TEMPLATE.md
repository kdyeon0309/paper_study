# 논문 제목

> 한 문장 요약: 이 논문은 (무엇을) (어떻게) 해서 (어떤 결과를) 얻었다.

이 틀은 세 번 읽는 것을 전제로 한다. 각 회독이 끝나면 논문 화면의 '이해 깊이'를 올린다. 빈칸을 Claude에게 채워달라고 하지 말고, 직접 쓴 다음 검토를 요청한다.

## 1회독 — 훑어보기 (10분)

제목, 초록, 서론, 각 절 제목, 그림과 표, 결론만 읽는다.

- **분류**: 어떤 종류의 논문인가 (새 구조 / 새 학습법 / 분석 / 벤치마크 / 서베이)
- **맥락**: 어떤 논문들 위에 서 있나. 무엇을 대체하려 하나
- **기여**: 저자가 주장하는 기여를 두세 줄로
- **계속 읽을 것인가**: 왜

## 2회독 — 정독 (1시간)

증명과 세부 유도는 건너뛰되, 그림과 표를 하나씩 직접 해석한다.

### 문제 정의
입력과 출력, 기존 방법이 실패하는 지점. 기호를 정의한다 (예: $x \in \mathbb{R}^{H \times W \times 3}$).

### 방법
구조와 학습 절차를 내 말로. 논문 문장을 옮겨 적지 않는다.

### 핵심 그림·표 읽기
| 그림/표 | 저자의 주장 | 그 주장을 뒷받침하는 숫자 | 내가 보기에 약한 곳 |
|---|---|---|---|
|  |  |  |  |

### 모르는 것
읽다 막힌 용어, 건너뛴 참고문헌. 다음에 읽을 것의 후보가 된다.

## 3회독 — 다시 만들어 보기

논문을 덮고, 같은 가정에서 출발해 저자의 결론에 도달할 수 있는지 본다.

### 유도
핵심 식 하나를 골라 처음부터 손으로 유도한다. 건너뛴 줄이 없어야 한다.

$$
L = \dots
$$

### 알고리즘
학습 한 스텝 또는 추론 절차를 의사코드로. 텐서 모양을 주석으로 단다.

```
입력: ...
1. ...
```

### 가정과 그것이 깨지는 경우
이 방법이 암묵적으로 가정하는 것 세 가지와, 각각이 성립하지 않는 상황.

1.
2.
3.

### 실험 검증
- 비교 대상은 공정한가 (같은 backbone, 같은 학습 길이, 같은 데이터인가)
- ablation이 주장의 어느 부분을 실제로 분리해 보여주는가
- 보고하지 않은 것은 무엇인가 (속도, 메모리, 분산, 실패 사례)

### 재현 계획
핵심 부분만 최소로 구현한다면: 데이터, 모델 크기, 예상 시간, 통과 기준(어떤 숫자가 나오면 맞게 짠 것인가).
