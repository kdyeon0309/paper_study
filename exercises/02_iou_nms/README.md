# 02. IoU와 NMS

YOLO를 읽었다면 수없이 본 두 연산. 읽은 것과 버그 없이 짜는 것은 다르다.

## 구현할 것 (`solution.py`)

```python
box_iou(a, b)                        # a: [N, 4], b: [M, 4] (x1, y1, x2, y2)  ->  [N, M]
nms(boxes, scores, iou_threshold)    # boxes: [N, 4], scores: [N]  ->  남긴 상자의 인덱스 (점수 내림차순)
```

- 상자는 `x1 <= x2`, `y1 <= y2`. 변이 맞닿기만 한 상자의 IoU는 0이다.
- NMS는 점수가 가장 높은 상자를 남기고, 그 상자와 IoU가 **임계값보다 큰**(`>`) 상자를 지운다. 같으면 남긴다.
- 넓이가 0인 상자가 섞여 있어도 nan이 나오면 안 된다.

## 손으로 먼저

1. `[0,0,2,2]` 와 `[1,0,3,2]` 의 IoU를 계산한다 (답: 1/3).
2. `box_iou` 를 이중 for 문 없이 브로드캐스팅으로 쓰려면 `a[:, None, :]` 와 `b[None, :, :]` 의 모양이 어떻게 되는지 적어본다.
3. NMS의 시간 복잡도는? 최악의 경우는 어떤 입력인가?
